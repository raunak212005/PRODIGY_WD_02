# Prodigy InfoTech Web Development Internship - Task 02

## 📌 Project Overview
This repository contains the completion of **Task 2** for the **Web Development Internship** at **Prodigy InfoTech**. The objective was to develop a **Stopwatch Web Application** using **HTML, CSS, and JavaScript**. The stopwatch allows users to accurately measure elapsed time with features such as start, pause, reset, and lap time recording.

## 🛠️ Technologies Used
* **HTML5** (Structure)
* **CSS3** (Styling & Responsive Design)
* **JavaScript (ES6)** (Functionality & Interactivity)

## ✨ Features Implemented
* Start the stopwatch with a single click.
* Pause and resume the stopwatch without losing elapsed time.
* Reset the stopwatch to its initial state.
* Record and display multiple lap times.
* Responsive and user-friendly interface.
* Smooth button animations and clean UI design.
* Accurate time tracking using JavaScript timing functions.

## 📊 Project Functionality
1. **Start Stopwatch:** Begins counting elapsed time.
2. **Pause/Resume:** Stops and continues the timer while preserving the recorded time.
3. **Reset:** Clears the timer and lap records.
4. **Lap Time Recording:** Saves multiple lap times for performance tracking.
5. **Responsive Design:** Works seamlessly across desktops, tablets, and mobile devices.

## 📁 Files in this Repository
* `index.html` – Structure of the stopwatch application.
* `style.css` – Styling and responsive design.
* `script.js` – Stopwatch logic and functionality.
* `README.md` – Project documentation.
